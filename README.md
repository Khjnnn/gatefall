# Gatefall — 라온시 · v0.27.36

귀환자 강윤과 제7방위대가 검은 탑의 범람을 막는 모바일 디펜스입니다. 각성자를 직접 움직이며 자동 공격하고, 결계주를 건설·강화·조합해 도시 결계를 지킵니다. 현재 일반 캠페인은 **종현동1-1~1-14**입니다. 7개 월드/240스테이지는 [장기 기획](Docs/Design/GATEFALL_240_STAGE_CAMPAIGN_PLAN.md)이며 구현 완료 수가 아닙니다.

Android 우선입니다. iOS·실제 사람의 재미 평가·실기기 성능과 청감은 보류 상태이며 새 PC 배포물은 만들지 않습니다.

## GitHub에서 프로젝트 열기

```powershell
git clone https://github.com/Khjnnn/gatefall.git
```

Unity Hub에서 복제한 `gatefall` 폴더를 추가하고 Unity `6000.6.7f1`로 엽니다. Android 빌드에는 해당 Editor의 Android Build Support, SDK/NDK 및 OpenJDK가 필요합니다. 설치 후 `Build-Gatefall.cmd` 또는 `Tools/build-delivery.ps1`로 회귀 검사와 Android APK 빌드를 실행할 수 있습니다.

저장소에는 Unity 소스, 게임에서 사용하는 자체 에셋, 기획 문서, 테스트 및 빌드 도구를 포함합니다. APK는 로컬에서 생성합니다. 아래 APK·검증 결과·QA 캡처 링크는 작업 PC에 보관한 기록입니다. 검증 결과, 캡처 영상과 스크린샷, 에뮬레이터 디스크·저장은 로컬에 보관합니다.

- 개발용 Debug 서명·debuggable 테스트 APK입니다. 스토어용 서명/AAB·실기기 검증을 마친 파일은 아닙니다. v2서명·ZIP16KB 정렬과 세ARM64 ELF의LOAD16KB 정렬을 확인했습니다.

## 조작과 승리

| 행동 | 모바일 조작 |
|---|---|
| 이동·공격 | 왼쪽 조이스틱,공격은 자동 |
| 건설 | 빈 지점 → 해금된 결계주 선택 |
| 강화·조합 | 결계주 → 강화 또는 조합 목록 → 레시피 → 강조된 재료 선택 |
| 조합 위치 | 먼저 선택한 결계주 자리에 결과 생성. 상대가 하나여도 위치·사거리 확인 후 직접 선택 |
| 판매 | 판매를 두 번 눌러 확정 |
| 고유 스킬 | 오른쪽 아래 버튼 |
| 배속 | 상단 결계 체력 옆에서 1.25배와 2배 전환. 새 전투는 1.25배로 시작 |
| 일시정지 | 타워·조합 메뉴에서도 상단 정지 버튼 한 번. 앱 이탈도 자동 정지. 계속하기에서 이전 타워·조합 메뉴 복원 |
| 메뉴 닫기 | 실제 패널 바깥 탭. 모든 화면에 안전한 고정 빈 좌표는 없음 |

타워 메뉴·조합 선택 중에도 전투는 진행합니다. 메뉴 조작 중 이동 입력은 잠기며 카드·명시적인 일시정지는 전투를 멈춥니다. 성장 카드를 선택하면 열려 있던 타워 메뉴나 조합 상대 선택으로 돌아갑니다. 긴 QA 검토는 [HOME 후 실제 상태 확인 절차](Docs/QA/GATEFALL_LIVE_REVIEW_PROTOCOL_2026-11-01.md)를 따릅니다.

승리는 **전체 예약 적 출현·잔여0·결계 생존**입니다.1-6은 문지기 처치도 필요합니다.180초에 적이 남으면 계속 싸웁니다. 헌터는 쓰러진 뒤 전투 시간10초 후 부활합니다. 카드·일시정지 중 부활 시간도 멈추고2배속은 전투 시간에 함께 적용됩니다.

14작전의 건설 지점은14/18/14/24/24/24/24/22/24/24/24/24/24/24로 총308개입니다.1~4개 진입로의 긴 우회·지름길·합류를 사용합니다. [작전별 현재 데이터와 남은 문제](Docs/QA/GATEFALL_CURRENT_PLAYABLE_SCOPE_2026-11-01.md)를 참고하세요. 총 출현 수는 동시 화면 적 수가 아닙니다.

- 시작 마석은1-1~1-3 240,1-4~1-9 280,1-10~1-14 320입니다.
- 보급은30초 간격5회,초반 세 작전80씩 총400·이후100씩 총500입니다. 처치 보상과 카드의 즉시 마석은 별도입니다.
- 성장 카드는 1·3·5번째 보급에 최대 3회, 공명 촉매는 해금 작전에서 2·4번째 보급에 각 1개를 지급합니다. 호출 없이 진행하면 카드는 30/90/150초, 촉매는 60/120초입니다.
- 일반 1-4 이후의 선택 호출은 다음 웨이브를 최대 6초 앞당깁니다. 연결 보급을 먼저 받고 다음 보급도 당겨지므로 카드와 촉매 시각이 바뀔 수 있습니다. 위기 작전은 자동 일정으로 진행합니다.
- 기본 결계주는 창·봉인·붕괴·방벽·표식입니다. 1-11부터 기본 결계주와 2단계 조합 결과를 Lv3까지 강화할 수 있습니다. Lv3 강화 비용은 같은 결계주의 Lv2 강화보다 마석 35개 높습니다.
- 조합에는 Lv2 이상 재료 두 개, 마석, 촉매가 필요합니다. 두 재료가 소모되고 결과는 첫 재료 위치에 Lv1로 생성됩니다.

| Lv2 이상 재료 | 결과 | 추가 마석/촉매 |
|---|---|---:|
| 창+봉인 | 뇌격 |40/1|
| 창+붕괴 | 파쇄 |45/1|
| 봉인+붕괴 | 중력 |45/1|
| 뇌격+붕괴 | 종결 |80/1|
| 파쇄+봉인 /중력+창 | 종결 |75/1|
| 표식+창 | 관측창,1-14 완료 후 |40/1|
| 표식+봉인 | 추적, 1-11부터 |50/1|

추적 결계주는 Lv1에서 적 최대 3명에게 3초간 표식을 남기고 30% 감속을 겁니다. 표식 중인 적을 다른 공격 결계주로 때리면 추가 피해를 줍니다. Lv3에서는 최대 4명과 40% 감속으로 강화됩니다.

마석은 판 안 건설 재화,마핵은 판 밖 성장 재화입니다. 첫 완료 보상10~36,재도전2입니다. 표식의 실효 보너스는 이미 아군 피해에 포함되므로 중복 합산하지 않습니다.

## 저장·개발 이어가기

저장은 `Application.persistentDataPath/raon-profile.sav`,현재 형식v2입니다. 체크섬·정상 백업·실패 재시도와 명시적 포기 처리를 사용합니다. 판중 이어하기·실제 전원 차단의 모든 원자성을 검증했다고 주장하지 않습니다.

[HANDOFF_CLAUDE.md](HANDOFF_CLAUDE.md) 최상단·[task_plan.md](task_plan.md)·[progress.md](progress.md)와 버전별 JSON을 우선합니다. 오래된 해시 가드 도구는 현행에서 무조건 다시 실행하지 않습니다. 보호5556/5558과 보호 저장 경로는 조작하지 않습니다.

시작 씬은 `Assets/Scenes/Gatefall.unity`입니다. Editor를 닫고 `Build-Gatefall.cmd` 또는 아래로 Android만 빌드합니다.

```powershell
pwsh -NoProfile -File .\Tools\build-delivery.ps1
```
