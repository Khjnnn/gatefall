# Gatefall v0.25.1 — 승인된 다섯 개선 적용

검토 후 사용자 지시인 “전부 개선 진행”에 따라 기존 시스템을 다듬었다. 모바일 전용이며 반복 예약은 재개하지 않았다. v0.24.3 검증본과 중간 v0.25.0은 별도 보존했다.

## 1. 전투를 덜 가리는 메뉴

- 타워 기본 화면은 강화·조합·판매3칸, 폭464ref/높이222ref다. 조합은 별도2열 목록으로 펼치고 뒤로 돌아온다. 해금 후 최대4개 레시피도 두 줄에 표시된다.
- 타워/재료 선택 중에도 상단Pause가 표시되며 한 번 누르면 실제Pause로 들어간다. 기본 메뉴는LIVE다. 판매2회 확정·비활성 패널 입력 차단·단일 상대도 직접 재료 선택·생성 위치/사거리 안내를 유지했다.
- 사거리 내 적 수 옆에 **이번 전투 발사 수**를 표시한다. 현재 타워ID의 표시용 이벤트 집계이며 소모된 타워나 이전 판의 수를 새 타워에 합산하지 않는다. 저장 형식이나 피해 계산은 바꾸지 않았다.

## 2. 보강·조합에 투자할 이유

일반1-11/1-12의 후반4~6웨이브에 원래 있던 정예·공성만 동행하도록 조정했다. 이동속도는1.6배,HP는1-11에서1.35배/1-12에서1.6배다. 다른 적·초기3웨이브·다른 작전·위기 능력치·전체 출현 수/시각·재화는 유지한다. 모든 적의HP나 보상을 일괄 변경하지 않았다.

시드7/19/41×7/16개 상한×창/표식군집/뇌격 정책의 기준36·선택36조건을 비교했다. 첫 제시 카드 선택 규칙과 실제 카드36쌍이 일치한다. 지형에 따른 구매 순위/위치와 실제 구매 시각은 달라질 수 있어 순수 능력치 인과 실험으로 쓰지 않는다.

- 선택된16개 상한의18조건은 전부 결계300으로 전멸 승리했다. 비싼 조합 정책의 실제 타워 수는 상한16보다 적을 수 있다.
- 7창/490마석은 기존 두 작전 모두 결계300이었으나 선택 후1-11은181/286/129.2,1-12는180/228/132였다. 적은 투자로도 승리할 수 있지만 보강은 피해를 줄인다.
- 저투자 표식 정책은 일부 실패했다. 이는 배치/구매 정책 전체의 결과이며 표식 단독 성능이나 모든 편성의 결론이 아니다. 뇌격7개 정책은675마석으로 창7개와 비용도 다르다.
- 위기는 공유 지형만 바뀐다. 기존/선택 각각12조건을 확인해 모두 결계300이었으며 위기 적 능력치는 그대로다.

## 4. 자체 아트로 장소 구분

자체 V12도시 아틀라스를 재사용해4테마의 저채도 바닥과 큰 랜드마크를 배치했다. 1-11은 콘크리트 타일 반복 크기를 줄이고 훈련 코트,1-12는 하역장 페인트로 구분한다. 도로 아래 레이어에 두며 랜드마크는 도로/패드와 거리를 검사한다. 실제 v0.25.0에서 평평한 초록 받침과 상단 중앙 장식 문제를 발견해 v0.25.1에서 받침을 없애고 상단 중앙 후보를 제외했다.

이번에는 외부 코드·에셋을 복사하거나 새 비트맵을 생성하지 않았다. 기존 자체 콘크리트의 이전 생성 이력은 `GATEFALL_TRAINING_GROUND_ASSET_2026-11-01.md`에 보존한다. 네 테마 전부의 모든 작전을 이번 APK로 완주한 것은 아니다.
