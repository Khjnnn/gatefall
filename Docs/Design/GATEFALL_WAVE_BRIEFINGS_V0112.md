# v0.11.2 웨이브 예고 — 비교서 개선 2차

2026-10-29 task125. 기존 시작/웨이브 알림은 ActiveGate 한 방향만 표시해 실제 다방향 편성과 어긋날 수 있었다. 새 메뉴를 만들지 않고 같은 알림 영역에 실제 방향별 수와 핵심 적 역할을 보여 준다.

## 기획과 구현 범위

- 실제 SpawnGroup 스케줄에서 WaveBriefing을 읽는다. 웨이브 번호·총 수·방향별 수·종류별 수·첫/마지막 출현 시각을 스냅샷으로 제공한다. 예고와 실행 데이터를 이중 편집하지 않는다.
- 시작 알림은 첫 웨이브의 `웨이브1 · 서4·북3·동3 · 빠른 적` 같은 짧은 정보를 표시한다. 이후 출현3초 전 경고에서 해당 웨이브 예고를 한 번만 표시한다.
- 핵심 위협 표시는 문지기→공성→정예→빠른 적→일반 우선이다. 가장 많은 적 종류라는 뜻이 아니라 해당 편성에 포함된 주요 대응 대상이다.
- CombatEvent에 경고가 속한 Wave ID를 별도로 넣는다. 기존 Source의 타워/헌터 의미를 재사용하지 않는다. 1-6 보스는150초에 출현하므로147초 경고가 당시 시간슬롯 Wave4와 혼동되지 않아야 한다.
- 첫 웨이브 시작 안내와 입구별 반복 경고는 중복 알리지 않는다. 보스 공격 회피 알림은 별도로 유지한다. 카드/보급·성장·정리 HUD 구조를 늘리지 않는다.
- 출현 편성·시각·수치·경제·카드/촉매 상한·저장 형식·승리 조건은 변경하지 않는다. 수동 호출은 후속126의 별도 작업이다.

## 검증

스케줄의 전후 전체14작전×일반/위기 스냅샷 비교, 방향/종류 합계·보스 시각·조회 무변경·경고 소속 ID 검사를 수행한다. 기존 회귀/Android 빌드/서명·정렬을 통과한 APK에서 독립 AVD로 다방향 시작·다음 예고·보급/카드 뒤 표시·4:3 가독성과 중복 방지를 확인한다. 실제 사람의 이해도/재미·실기기는 별도 미검증이다.

실제 결과는 `TestResults/runtime-v0112.md`에 기록한다. 스냅샷은 실행 스케줄을 명시적으로 확인하는 자료이며 전 작전의 저작 방식을 외부 편집 데이터로 바꾼 것은 아니다.
