# 1-8 봉인 역할·보강 시점 검토

후속 [동일 지출 상한·위치·구매 순서 비교](../../TestResults/stage8-budget-review-v0114.md)에서도 봉인 투자의 상대 우위를 확인하지 못했다. 최종 판단은 화력 우선 안내 유지·수치 조정 보류이며 역할 효용 완성으로 해석하지 않는다.

2026-10-29 task116. 현재 v0.11.3/전멸 승리/일반 선택 호출 기준으로 검토한다. 먼저 실제 전투 모델을 비교하고 필요한 최소 변경을 결정한다. 초기1-1~1-3·다른 작전·타워 공통 수치·저장은 근거 없이 바꾸지 않는다.

현재1-8은 서·북2경로/10지점/102마리다. 빠른 적의 j%4 편성과 두 경로의 교대 때문에 웨이브마다 빠른 적의 주력이 서·북으로 번갈아 온다. 후반에는 정예·공성도 있어 봉인만으로 화력이 대체되는지,창 사거리와 겹치는 위치가 중요한지 확인해야 한다.

## 모델 계획

창@3/4를 공통으로 시작한다. 세 번째 타워는 창 또는 봉인,위치는@2 중앙 연결/@7 북쪽/@9 서쪽,시점은 시작/첫 보급/둘째 보급이다. 추가 보강 없음과 단계 보강(첫/둘째/셋째 보급에각세타워강화,넷째/다섯째에창추가)을 비교한다. 행동 간격은2초이며 자금 부족은 실제 규칙으로 처리한다. 봉인은 건설/강화 가격이 달라 지출을 별도로 기록하고 가짜 자금 보정은 하지 않는다.

시드7/19/41·카드off/on·미호출/가능 즉시 호출을 비교한다. 카드는 공통 피해→사거리→헌터→마석→감속→범위 순서다. 카드off로 타워 역할을 따로 확인하고 카드on의 선택·예산 차이를 단일 인과효과로 과장하지 않는다. 승패/최소결계/전멸시각/지출·봉인피해·빠른 적 감속 누적/결계도달 고유 수를 기록한다. 감속 누적은 살아 있는 빠른 적의 감속 상태를50ms 간격으로 표본화한 참고치다.

이 검토는 고정 정책 모델이며 사람의 재미나 최적 전략을 의미하지 않는다. Android는 새 분리 AVD와 합성 첫7작전 완료 저장으로 대표 정책을 확인한다. 기존5556/사용자 저장은 건드리지 않는다. 결과는 후속 실행 기록에 남기고 모든 경로의 실제 Android 비교나 사람 평가를 완료로 주장하지 않는다.

## 모델 결과와 적용 결정

8개 편성/정책 집합 각432조건, 총3456조건을 비교했다. 기본 편성의 세 타워 고정 정책은 모두 패배했다. 단계 보강 시 창 정책은 미호출54/54승·평균 최소결계243.8, 즉시 호출45/54승·218이었다. 봉인 정책은 미호출54/54승·148.8, 즉시 호출27/54승·81.4였다. 가격 차이를 보정하지 않은 실제 구매 정책의 결과이며 봉인의 인과 효과를 뜻하지 않는다.

빠른 적 무리로 종류를 대체한10/12/16초 후보는 고정 세 타워도 전승하여 제외했다. 종류/체력/총수를 유지하고 빠른 적만 앞/중간에 묶은 후보도 봉인의 상대 이점을 확인하지 못했다. 창3개를 공통으로 시작하고 네 번째 창/봉인을 추가하는 보조 정책에서는 단계 보강 양쪽 모두54/54승·결계300이었다. 같은 조건의 짝 비교에서도 봉인이 더 높은 결계를 남긴 사례가 없어, 이를 봉인 우위 또는 전략 다양성 완성으로 주장하지 않는다.

따라서 적 편성·타워 능력치·경제·초반 작전은 바꾸지 않는다. v0.11.4는1-8 안내를 '먼저 서·북 창 화력 보강, 봉인은 감속 보조, 후반 정예·공성 대비'로 정정한다. 봉인 투자의 상대 가치 문제는 별도 미해결 항목이다. Android에서는 창3개와 보조 봉인, 실제 보급 뒤 보강을 대표 확인한다.

함께 기존 UI만 정리한다. 호출 버튼에 현재 적과 다음 적이 겹친다는 위험을 명시하고, 타워 메뉴와 겹치는 일반 일시 안내를 패널 아래 또는 위의 빈 공간으로 옮긴다. 문지기 공격 예고는 기존 위치를 유지한다. 패널 배치/화면비 회귀25검사와 전체28스케줄 해시 동일을 확인했다. 새 APK/실제 Android 결과는 완료 후 별도 기록한다.
