# 직접 플레이 확인 목록 · v0.33.x

스크립트 모델과 에뮬레이터 자동 입력으로는 판단할 수 없는 것만 모았다. 30~40분이면 끝난다. 각 항목에 짧게 "예/아니오 + 한 줄"만 적어 주면 다음 조정에 바로 쓴다.

준비: 최신 APK를 설치하고, 3장을 진행 중인 저장(또는 새로 시작)으로 한다. 각성자는 평소처럼 움직여도 된다. 모델은 각성자가 서 있기만 한다고 가정했다.

## 1. 난이도 (15분)

| # | 할 일 | 볼 것 |
| --- | --- | --- |
| 1 | 3-3 복선 정비로를 한 번 | 처음 하는 사람이 3별을 기대할 만한가, 북쪽이 갑자기 뚫린다고 느끼는가 |
| 2 | 3-6 환승 앞 분기장을 한 번, 쇄도 → 종결 조합을 써서 | 조합을 쓰면 오히려 손해라고 느끼는가, 어느 방향에서 새는지 화면에서 알 수 있는가 |
| 3 | 3-2를 끝내고 3-3으로 넘어갈 때 | 난이도가 갑자기 뛴다고 느끼는가 (배율 1.17 → 2.2) |
| 4 | 위기 작전 하나 | 일반 작전 대비 "한 단계 더 어렵다"는 정도인가, 불가능하다고 느끼는가 |

## 2. 조합과 계승 종결 (10분)

| # | 할 일 | 볼 것 |
| --- | --- | --- |
| 5 | 결계주를 눌러 조합 목록을 연다 | 카드의 재료 줄("붕괴 + 쇄도")과 상황 문구("일렬 선로에 강함")를 읽었는가 |
| 6 | 재료를 고르는 중의 공격 모양과 "선로 겹침" 표시 | 무엇을 뜻하는지 설명 없이 이해되는가, 자리 선택을 바꾸게 만드는가 |
| 7 | 쇄도 종결을 길을 따라 한 번, 길을 가로질러 한 번 | 차이가 눈에 보이는가 |
| 8 | 관측 종결과 표식 결계주 | 일반 종결과 다르게 느껴지는가 (지금은 수치상 기존과 비슷하다) |

## 3. 하트와 홈 (10분)

| # | 할 일 | 볼 것 |
| --- | --- | --- |
| 9 | 홈 화면을 처음 본 인상 | 출전 버튼을 바로 찾는가, 상단 하트 표시(기본/여분/타이머)가 읽히는가 |
| 10 | 연속으로 몇 판 | 하트가 모자랄 것 같다는 압박이 있는가, 전혀 없는가 |
| 11 | 하트를 0으로 만들고 출전 (상점에서 써서 줄이기 어렵다면 알려 주세요, 시험 저장을 만들어 드림) | 부족 창의 세 선택이 분명한가, 광고 버튼이 강요처럼 느껴지는가 |
| 12 | 결과 화면의 "광고 보고 2배" | 눈에 거슬리는가, 쓰고 싶은가 |

## 4. 상점과 일일 콘텐츠 (5분)

| # | 할 일 | 볼 것 |
| --- | --- | --- |
| 13 | 상점 → 상자 → 열기 | 결과 창이 만족스러운가, 확률표 버튼을 찾을 수 있는가 |
| 14 | 결계주 → 카드에서 등급 올리기 | 결계주 탭이 편성 화면부터 열리는데, 카드가 먼저인 편이 나은가 |
| 15 | 룰렛·임무·출석·패스 | 어디서 무엇을 받는지 헷갈리는 곳이 있는가 |

## 적어 줄 것

- 가장 거슬렸던 것 하나
- 가장 좋았던 것 하나
- 기기 이름과 화면 크기 (실기기로 했다면)
