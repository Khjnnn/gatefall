# v0.14.0 — 원래 물량의5~8배와 작은 군집

사용자 요청: 앞선2배보다 많은5~8배 물량, 작은 저해상도 적으로 부하 감소. 배수는 같은 **v0.12.1 원래 편성 기준**이다. v0.13.0에서 다시5~8배가 아니다.

## 전투 편성

| 작전 | 원래 대비 | 총 적(보스 포함) |
|---|---:|---:|
|1-1 /1-2 /1-3|5배|330 /460 /450|
|1-4 /1-5 /1-6|6배|768 /780 /883|
|1-7 /1-8 /1-9|6배|552 /612 /624|
|1-10 /1-11 /1-12|8배|864 /816 /880|
|1-13 /1-14|8배|928 /944|

원래 적1기 뒤에 작은 일반 적4/5/7기를 더한다. 빠른 적·정예·공성·보스의 수와 입구 역할은 유지한다. 보스는 복제하지 않는다. 작은 일반 적은 3열(중심선±.32거리)로 도로 폭 안에 흐른다. 일반 적은 원래 체력의.12배라 기본 창과 헌터로 대부분 한 발에 처치한다. 정예·공성·보스의 체력은 유지한다.

추가 작은 마수의 공격은1, 원래 일반 적7/빠른 적7/정예13/공성24/보스22다. 추가 마수는4처치당 전투 마석1을 누적 지급하고, 원래 편성의 보상은 그대로다. 많은 적을 잡는 흐름을 살리면서 재화와 결계 피해가 물량만큼 폭증하는 것을 줄인다. 별도 화폐/메뉴/성장 시스템은 추가하지 않는다.

창 간격.46초/타워·헌터 탄속28/30과 기존 사거리·가격·조합법은 유지한다. 기본 단일 탄이 이미 치명 피해를 예약한 적에는 다른 단일 공격이 중복 발사되지 않게 한다. 만료 탄의 예약은 해제한다. 폭발/연쇄의 실제 범위 피해는 예약 때문에 누락하지 않는다.

6웨이브 전멸 승리, 선택 호출, 보급5회300/카드3/촉매2 상한, 영구 보상/해금/저장 형식은 유지한다.

## 작은 표시와 연산

- 일반/빠른 적의 Unity 임포트 상한64px, 정예/공성128px, 보스256px. 원본 자체 PNG는 보존하고 임포트 해상도와 월드 크기를 분리한다. 기본 일반 적 표시.42, 빠른 적.46배로 줄이고 정예·공성·보스의 위협 실루엣은 남긴다.
- 일반 적마다7개 표시 컴포넌트와 루트를 생성하는 대신24개 깊이 행의 재사용 메시로 몸체를 그린다. 감소/표식/묶임은 별도 공통 링 메시로 표시한다. 정예·빠른 적·공성·보스는 기존 개별 체력/경고 표시를 유지한다. 개별 일반 적 체력바는 없앤다.
- 적 배치가 늘어도 예약 그룹을 적 한 기마다 늘리지 않고 원래 편성1그룹+동행1그룹으로 묶는다. 헌터/방벽의 묶인 적 수는 스텝당 한 번 집계한다. 표적 후보 버퍼를 재사용하고 폭발 표적의 군집 점수는 정렬 전에 한 번 계산한다.
- 작은 적의 처치 파편은3개, 큰 적은9개로 구분하며 일반 효과 풀 상한220을 유지한다. 적·효과의 위치 보간과 공격/처치 효과는 계속 사용한다.
- 구현 참고: [Unity TextureImporter](https://docs.unity.com/en-us/engine/6000.0/script-reference/unityeditor/textureimporter), [Mesh.SetTriangles](https://docs.unity.com/en-us/engine/6000.0/script-reference/unityengine/mesh/settriangles). 기존 자체 이미지의 임포트와 코드 렌더링 변경이며 외부 게임 이미지/코드를 사용하지 않는다.

## 검증과 한계

0.13.0과 같은 정책/시드의168조건을 비교한다. 현재 분산/강화42승씩, 조합보충35승7패(이전36승6패). 초반27 능동 보강 조건은 결계300을 유지한다. 시작재화로 창 세 개만 두고 추가 행동이 없는 정책은1-2에서 패배하므로 모든 초반 무조작을 보장하지 않는다. 조합 정책의1-8/1-9/1-11 일부 실패를 기록하고 최적 플레이/사람의 재미 평가로 주장하지 않는다. 시드별 카드/행동 차이와 같은 결과를 구분한다.

동일 위치·체력의128/384/768적과12타워를 둔90스텝 호스트 .NET 부하 비교에서 최종 피해·체력합·투사체 수는 동일했다. 768적의 기준435.8ms/22.31MB 할당→초기 최적화25.0ms/42KB, 빌드 전 재검사는29.0ms/42KB였다. 호스트 부하·JIT 영향을 받는 연산/할당 측정이며 Android FPS·총 RAM·기기 배터리 수치가 아니다. 군집 최대180과1전투초 최대16처치는 자동 정책의 관측 최대다.

최종 Android의 설치/저장·5/6/8배 전투·실제 작은 메시 표시·프레임 결과는 `TestResults/runtime-v0140.md`에 별도로 기록한다. 실기기·사람의 재미/청감·iOS 및14작전 전수 완주는 보류한다.

0.14.1 렌더 보완: 전투 코어는0.14.0과같고, 행 메시의정점/UV/인덱스를최대용량까지재사용한다. UV/인덱스는용량성장시에만갱신하고평상시는위치·색만보낸다. Sprite의규격/UV를초기캐시해개체마다Unity속성을반복조회하지않으며일시정지시동일군집업로드를생략한다.0.14.0 APK/초반검증과최종0.14.1 검증을구분해기록한다.
