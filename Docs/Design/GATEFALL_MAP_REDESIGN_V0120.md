# v0.12.0 맵 다양화 · 전투 개체 표시

사용자 2026-10-30 요청: 반복되는 맵을 다양한 길목으로 바꾸고 적·타워를 줄여 넓게 보이게 한다. 이전 예약 개발은 재개하지 않는다.

## 설계와 구현

Realm의 경로별 위협, 합류 지점, 굴곡을 활용한 사거리 중첩이라는 원리를 참고했다. 실제 경로 좌표, 이미지, 코드와 배치 데이터를 가져오지 않았다. 새 경로는 Gatefall에서 직접 정의했다.

`BattlefieldLayouts`가 캠페인 경로와 건설 지점을 제공하고, 시뮬레이션과 `ArenaView.Ground`가 같은 경로를 사용한다. 배경 그림에 그려진 가짜 길과 실제 몬스터 경로가 따로 존재하지 않는다. 도로 테두리·노면·중앙선은 그 좌표로 렌더링한다. 사용하지 않는 입구의 도로는 그리지 않는다.

## 표시 크기와 에셋

타워0.70, 일반 적0.68, 공성0.75, 보스0.60, 헌터0.80, 결계 본체0.76의 표시 배율. 체력바·표식·감속·발사 효과 높이를 조정했다. 공격 수치/사거리·몬스터 경로 판정·타워 터치 박스·메뉴 크기는 유지한다. 이는 이미지 표시 축소이며 물리 판정 축소가 아니다.

V12의 새 바닥·아스팔트·투명 도시 소품4개 아틀라스는 imagegen으로 자체 생성했다. 바닥은 작은 무늬로 반복하고 소품은 크기/위치를 달리해 도로·지점과 겹치지 않는 곳에만 배치한다. 건물은 기존처럼 장식이며 새 이동 장애물 시스템은 추가하지 않았다. 전투 타워/적 원화는 기존 자체 V6 아트의 배율을 조정해 사용한다. 도시 선택 화면은 이번 전투 맵 개편 범위에 포함하지 않았다.
