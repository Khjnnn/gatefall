task126 모바일 통합. 후보의 비교/제외 결과는 `GATEFALL_WAVE_CALL_CANDIDATE_V1.md`, 후보 단계의46개 검사는 과거 기록이다. 이번 통합은49개 호출 불변 검사/24개 모바일 검사와 별도 Android 실행을 기준으로 한다.

## 채택 범위

일반1-4이후에서만 호출을 노출한다. 첫1-1~1-3/실험실/위기는 기존 진행을 유지한다. 다음 첫 출현3~13초 전, 현재 웨이브 첫 출현10초 후에 최대6초 당긴다. 현재 웨이브 출현표·행위자 시간은 유지하고 다음 이후의 출현표만 당긴다. 최소3초 대비 시간을 보장한다. 원래 총 적 수·전멸/보스 승리 조건·성장·저장은 그대로다.

대가는 남은 적과 새 적이 겹치는 압박이다. 보상은 다음 보급60 선지급이며, 다음 보급 원본은 다시 지급하지 않는다. 총5회300/카드3회/촉매2개를 유지한다.3·5웨이브 촉매,2·4·6웨이브 카드라는 기존 공급 순서에 맞춰 당긴다. 추가 화폐·영웅 충전 보너스는 없다.

## 모바일 표현/입력

호출 창에만 하단 중앙 한 개 버튼을 표시한다. 당길 시간,다음 웨이브 방향별 수/위협,현재 남은 적과60 선지급을3줄로 읽는다. 이동 스틱/회피와 분리하며 같은 곳에 보이는 타워보다 버튼 입력이 우선한다. 메뉴/카드/일시정지 중에는 노출하지 않는다. 입력에는 표시 중인 웨이브 번호가 담기므로 누르는 동안 대상이 바뀌면 호출하지 않는다.

진행 막대는 고정Elapsed/30이 아니라 실제 공급 시점을 따른다. 경과 시간은 실제 전투 시간이다. 선지급 알림은 호출 보급임을 표시하고 카드가 열리면 선택 후 다시 보여 준다. 촉매 부족 안내도 호출 가능 작전에서는3·5웨이브 기준으로 표시한다. UI 실행 로그와 마지막 전투 기록에 호출/공급/카드/촉매 상한을 남긴다.
