# 월드별 기본 결계주와 조합 확장안

> 2026-11-06 후속 우선안: [10챕터 전략](GATEFALL_10_CHAPTER_STRATEGY_2026-11-06.md)의 기본9종/신규4종·상위 조합 경로 예산을 따른다. 아래 문서의 현황/매월드1신규/기본11종은 과거 제안이며 현재 구현 수량이 아니다. 현 구현은 기본5종/1차5결과/종결1종/9레시피다. 새 기본·조합은 아직 기획이다.

상태: 기획 제안. 아래 새 타워·조합·편성 및 해금은 구현되지 않았고, 가격과 성능은 플레이 테스트로 확정한다. 기준은 기존 3분 모바일 캠페인과 7월드 240스테이지 제안이다. 기존 스테이지와 1-6 봉인, 세희·백도하 해금은 유지한다.

## 1. 수량과 원칙

현재 기본 결계주 4종(창·봉인·붕괴·방벽), 1차 조합 3종(뇌격·파쇄·중력), 최종 종결 조합 3경로가 있다. 여기에 **월드당 기본 1종, 1차 조합식 1개**를 제안한다. 전부 출시된 시점의 계획 수량은 기본 11종, 1차 결과 10종, 최종 결과 1종, 조합 경로 13개(기존 6 + 신규 7)다. 방벽은 기본이지만 현재 기존 조합 재료는 아니다. 서로 다른 결과 종류와 레시피 경로의 수를 구분한다.

3분 전투 안에서 새 역할을 명확히 느끼되 다른 타워를 대체하지 않도록 한다. 모든 신규 조합은 새 기본 타워와 기존 기본 타워를 섞는다. 신규 타워끼리의 연쇄 레시피나 신규 최종 조합은 우선 추가하지 않는다. 기존 최종 종결로 가는 세 경로는 그대로 둔다. 특정 신규 타워나 조합이 해당 월드의 유일한 공략이 되지 않게 한다.

## 2. 전투 전 편성: 메뉴를 간결하게

- 기본 결계주 중 **최대 4종**을 출전 전 선택한다. 고정 슬롯은 없으며 4종 미만을 해금한 초반에는 보유한 타워만 표시한다. 조합 결과는 기본 슬롯을 차지하지 않는다.
- 신규 편성 기본값은 기존 창·봉인·붕괴·방벽 중 해금된 순서대로 최대 4개. 신규 해금 시 자동 교체하지 않는다. 월드 타워 소개 전투에는 무료 미리 써보기 선택을 제공하고, 종료 시 기존 편성을 그대로 복원한다. 일시 사용도 해당 전투의 4종 한도를 지킨다.
- 전투 중 건설 패널에는 편성한 기본 타워만, 조합 버튼에는 그 타워로 실현 가능한 해금 레시피만 표시한다. 보유 재료가 없더라도 조건을 표시할 수 있다. 도감은 모든 레시피와 잠금 조건을 보여 준다.
- 최종 종결은 기존 기본 세 종류를 선택한 경우 기존 1차 조합과 세 번째 기본 타워를 이용해 만들 수 있다. 편성 화면에 만들 수 있는 결과와 누락된 재료를 미리 보여 준다.
- 기본 타워 해금은 해당 월드 초반, 레시피는 그 기본 타워를 연습한 뒤 중반에 순차 지급한다. 잠긴 신규 조합은 무작위 획득이 아니라 캠페인 클리어로 해금한다. 실패·재도전·전투 종료 시 전투 내 타워와 마석은 초기화한다.

편성은 기존에 없는 시스템이므로 초반 게임이 복잡해지지 않도록 1-1~1-6에는 편성 화면을 강제하지 않는다. 1-10에서 신규 결계주를 해금한 뒤 첫 교체를 안내한다. 기존 세이브는 자동 기본 편성으로 이행하고, 잠금/보유 정보를 안전하게 저장한다.

## 3. 월드별 신규 기본 결계주

| 월드 | 신규 기본 결계주 / 제안 해금 | 역할 | Lv1 → Lv2 강화 방향 | 유리한 상황 / 한계 |
|---|---|---|---|---|
| 1 종현동 | **표식** / 1-10 | 가장 앞선 적 한 명에 표식. 표식 대상이 타워에 맞을 때 추가 피해 | 표식 추가 피해 소폭 증가 | 정예를 여러 타워가 함께 공격할 때. 일반 무리를 단독으로 막기 어려움 |
| 2 다솜동 | **잔화** / 2-6 | 짧은 시간 바닥에 피해 구역을 남김 | 피해 구역 지속 또는 피해 증가 | 느리게 몰려오는 적. 빠르게 지나가는 적과 흩어진 적에는 약함 |
| 3 라온역 | **관통** / 3-6 | 직선 방향의 앞뒤 적을 제한 수만큼 관통 사격 | 관통 대상 수 또는 피해 증가 | 좁은 터널에 줄지어 오는 적. 갈라진 경로에는 약함 |
| 4 라온강 | **파도** / 4-6 | 짧은 간격으로 주변 적을 감속하는 펄스. 적을 밀거나 경로를 바꾸지는 않음 | 펄스 범위 또는 지속 증가 | 전환된 길의 군집을 오래 붙잡는 보조. 단독 피해는 낮음 |
| 5 한울 | **기동** / 5-6 | 주변 공격 결계주에 제한된 공격 속도 보너스 | 보너스 또는 범위 소폭 증가 | 몇 개의 화력 타워가 모인 전선. 지원 타워 자체는 공격하지 않고, 공성 적을 저지하지 못함 |
| 6 누리 | **추적** / 6-6 | 비행 적을 우선하는 단일 표적 사격. 비행 적이 없으면 지상도 공격 | 단일 피해 증가 | 비행·지상 혼합에서 누수를 줄임. 무리 처리에는 약함 |
| 7 시청 | **반향** / 7-6 | 한 적에게 두 번의 약한 사격을 짧은 간격으로 발사 | 두 번째 사격 피해 증가 | 체력 높은 적. 사격 중 대상이 사라지면 남은 사격을 낭비할 수 있음 |

표식·기동의 중첩 여부와 상한, 표적 우선순위, 파도의 감속 적용 주기, 잔화의 구역 중첩 여부는 상세 구현 전에 확정한다. 초기 제안은 같은 종류의 중복 보너스 비중첩이며, 플레이어 화면에 효과 대상과 지속을 표시한다. 공성·보스는 현재의 감속 저항과 저지 무시 규칙을 우선 적용한다. 모든 타워가 비행 적을 공격할 수 있도록 가정하며, 추적은 비행 대응의 필수가 아닌 우선 타깃 선택이다.

## 4. 신규 조합식과 교환 관계

각 재료는 서로 다른 보유 타워 Lv2 하나씩이다. 재료 두 개를 소비하고 재료가 있던 지점 중 하나에 결과가 생기며, 남은 지점은 빈다. 기존 1차 조합과 같은 공명 촉매 1개가 필요하다. 결과는 Lv1에서 시작하고 Lv2로 한 번 강화한다. 세부 수치는 재료 두 개의 단순 상위가 아니라 **특화 역할과 방어 공백**을 기준으로 정한다.

| 월드 | 조합식 / 제안 해금 | 결과 · 기능 | 선택할 이유와 포기하는 것 |
|---|---|---|---|
| 1 | 표식 Lv2 + 창 Lv2 / 1-14 | **관측창**: 표식된 선두 정예를 우선 공격하는 집중형 타워 | 정예 처리가 강해지지만 두 지점의 공격과 별도 표식 지원을 잃음 |
| 2 | 잔화 Lv2 + 붕괴 Lv2 / 2-12 | **화염진**: 제한된 범위에 폭격하고 짧은 잔화 지대를 남김 | 밀집 무리에 유리하지만 즉각적인 단일 집중과 두 지점 방어는 약해짐 |
| 3 | 관통 Lv2 + 봉인 Lv2 / 3-12 | **쇄도봉**: 직선 관통 대상에 짧은 감속을 부여 | 일렬로 나오는 적을 동시에 늦추고 공격. 갈라지는 적과 별도 봉인 범위를 놓침 |
| 4 | 파도 Lv2 + 붕괴 Lv2 / 4-12 | **파문포**: 착탄 지점에 피해와 짧은 감속 적용 | 경로가 바뀌는 지점의 군집을 처리. 파도의 지속적인 주변 제어를 잃음 |
| 5 | 기동 Lv2 + 창 Lv2 / 5-12 | **가속창**: 공격 간격이 짧은 단일 화력 타워 | 공성 적 집중 대응. 주변 타워에 주던 속도 지원을 잃음 |
| 6 | 추적 Lv2 + 봉인 Lv2 / 6-12 | **구속추적**: 비행 적을 우선해 공격하고 짧게 감속 | 빠른 비행 적 대응. 지상 다중 감속과 독립된 두 방어 위치를 잃음 |
| 7 | 반향 Lv2 + 붕괴 Lv2 / 7-12 | **여진포**: 한 지점에 두 차례 작은 간격의 폭발 | 예고된 밀집과 정예 혼합에 유리. 움직인 적에게 두 번째 폭발이 빗나갈 수 있음 |

조합 해금 스테이지 자체는 기본 타워 소개로부터 충분히 연습할 수 있는 위치를 잡은 초안이다. 이전 월드의 기본 타워·조합은 새 월드에서도 편성할 수 있다. 타워 7종과 조합 결과 7종의 명칭은 작업명이다.

## 5. 자원과 전투 내 타이밍 초안

현재 기본 타워 건설 40~65마석, 강화 30~55마석, 1차 조합 추가 40~45마석과 촉매 1개가 기준이다. 신규 가격은 역할별로 기존 범위 안에서 **시험**하고, 고정하거나 기존 종결의 총비용을 바꾸지 않는다. 60초와 120초의 촉매 지급도 기존 규칙을 유지한다.

- 준비 단계에서 기본 타워를 먼저 세우고, 30~60초에 새 기본의 역할을 관찰한다.
- 충분한 자원과 촉매가 있으면 60초 이후 조합을 선택할 수 있도록 목표로 한다. 처치 수입·카드에 따라 반드시 그 시간에 가능하다고 보장하지 않는다.
- 조합을 건너뛰고 기본 타워 분산·강화를 선택해도 승리 가능해야 한다. 조합이 더 유리한 상황에서는 결계 체력, 대응 시간, 재화 효율 중 적어도 하나의 체감 가능한 이점이 있어야 한다.
- 전투 밖 영구 성장이나 반복 플레이가 새 타워의 사용 자체에 필요하지 않도록, 캠페인 해금 이후 별도 구매 비용 없이 사용할 수 있게 제안한다.

## 6. 모바일 UI와 접근성

출전 화면에 `편성 4/4`, 역할 태그(단일·감속·범위·저지·지원)와 조합 가능 결과를 간단히 표시한다. 선택 가능한 타워가 4종 이하면 자동 편성하고 편집 버튼은 작게 제공한다. 해금 연출은 하나의 카드로 역할과 첫 권장 조합만 소개한다. 전투 중 표식은 적 위의 작은 고대비 표식, 구역 공격은 바닥 윤곽, 비행은 그림자와 높이 차로 구분한다. 색만으로 역할을 구분하지 않는다.

조합 미리보기에는 재료, 레벨, 마석·촉매, 결과의 역할, **비게 되는 지점**을 표시한다. 스크롤과 작은 버튼이 필요한 13개 레시피 전체를 전투 중 한 번에 나열하지 않는다. 앱 배경 복귀, 손가락 취소, 일시정지, 무료 미리 쓰기 편성 복원은 별도 모바일 검증 대상이다.

## 7. 검증·제작 순서

1. 기존 1-1~1-6의 창 범용성 및 조합 가치를 검증한다. 확장 타워 추가를 기존 밸런스 문제의 대체 해결책으로 삼지 않는다.
2. 편성 4종과 세이브 마이그레이션을 독립적으로 구현하고, 기존 플레이어는 편성 선택 없이 기존 1-1~1-6을 시작할 수 있는지 테스트한다.
3. 월드 1 표식·관측창만 먼저 제작해 1-10/1-14 해금, 기본 타워 없이도 깰 수 있는 대조 전략, 전투 내 조합과 판매·환불·촉매 보존, 실기기 메뉴 가독성을 시험한다.
4. 월드 2 잔화·화염진을 제작해 밀집 적 대비 효과와 3분 경제를 검증한다. 이후 월드 출시와 함께 한 쌍씩 제작한다.
5. 각 타워마다 기본 단독 역할, Lv2와 조합의 의미, 2개 이상의 승리 가능한 편성, 기존 최종 조합 호환, 30/60/144fps와 Android 성능, 적 실루엣 가독성을 확인한다. 카드·시드·구매 타이밍을 통제한 비교와 사람의 플레이를 함께 기록한다.

v0.10.0에서는 1-7~1-14, 1-10 표식 해금, 1-14 관측창 조합 해금과 최대 4종 편성을 시험 구현했다. v0.10.1에서 편성 결과 미리보기를 추가했다. 무료 대여와 도감은 아직 구현하지 않았다. 다른 월드의 해금 시점, 수치와 개별 역할은 계획이다. 소스의 타워 enum·고정 크기 배열·직렬화·조합 카드와 UI를 확장할 때 저장 호환성과 잘못된 ID 입력을 검사해야 한다. World 2~7 비행·경로 전환·전력 장애는 캠페인 기획상의 미구현 기능이다.
