# Gatefall 도시 결계 UI 적용

이 문서는0.28.12의 이전 적용 기록이다. 사용자 피드백을 반영한 현행 규격은 `GATEFALL_REFINED_UI_2026-11-06.md`의0.28.13/무광1.1.0을 따른다.

2026-11-06 · `gatefall-style` 1.0.0 · Android 0.28.12 / code 129

건설·강화·조합의 공통 표면, 역할 표시와 상태 문구를 도시 결계 스타일로 연결했다. 기존 도시의 손채색 2D와 타워 실루엣을 유지하며, 남색 표면과 밝은 중립 글자 위에 의미 색을 좁게 사용한다.

## 적용 결과

| 요소 | 공통 표현 | 구현 |
|---|---|---|
| 건설 | 어두운 면, 역할별 얇은 테두리, 역할명·타워 아이콘·비용 | 역할 배지와 부족/상한/불가 배지의 공간을 확보하고 아이콘을 그 아래에 배치 |
| 강화 | 금색 상승 심벌·프레임, 중립 제목·비용 | 실제 강화 가능 여부와 부족/잠금/완료 상태를 표시 |
| 조합 | 보라색 결합 심벌·프레임, 중립 제목 | 실제 준비 수·재료/해금 사유를 표시하며 조합 결과명도 같은 글자색 사용 |
| 판매 확인 | 어두운 장밋빛 면과 흰 안내 | 기존 두 번 누르기 동작을 유지하고 긴 확인 문구를 14 HUD 단위로 표시 |
| 패널·버튼 | 반경 16/12/8, 얕은 깊이, 동일한 nine-slice | 기존 논리 좌표와 터치 영역 안에서 두 렌더 경로가 같은 텍스처 사용 |

`GatefallArt`의 역할색·기본 글자색·폰트와 `MobileHud.Theme`의 표면이 같은 생성 상수를 참조한다. 카드 면은 역할색을 6%만 섞고 테두리·아이콘·배지에 색을 집중한다. 표면은 캐시하며 매 프레임 생성하지 않는다. 민트 주요 행동과 금색 강화, 보라색 조합, 타워 역할의 토큰은 의미별로 분리했다.

전투 수치·가격·레시피·해금·입력 판정·저장 형식은 바꾸지 않았다. 출발점 `ab2ba77`과 비교해 Core 6개 파일의 SHA256이 모두 같다. 챕터2 기획 작업은 이 UI 변경에 포함하지 않았다.

## 공통 기준과 유지 방법

- 기준: `Docs/Design/city-barrier-ui-20261106/tokens.json` — 74개 토큰, 11개 역할과 컴포넌트, 7개 상태 규칙.
- 생성 코드: `Assets/Scripts/Presentation/GatefallUiStyle.Generated.cs`.
- 토큰을 수정하면 `python -X utf8 Tools/sync-city-barrier-style.py --write`로 생성한다.
- `pwsh -NoProfile -File Tools/verify-city-barrier-style.ps1`로 동기화·참조·색 대비를 검사한다. 이 검사는 표준 `build-delivery.ps1`에도 연결했다.
- 실제 Unity의 캐시 표면과 한국어 글자 크기는 `Assets/Editor/CityBarrierUiAudit.cs`가 기존 프로젝트 검증과 함께 확인한다.

토큰은 Gatefall 자체 규격이다. Realm Defense는 경로·지점·위협의 가독성, Random Dice는 반복 카드의 정보 순서와 역할·단계 식별에 참고했다. 원작 UI의 정확한 HEX·폰트·반경·모션을 추출한 값으로 주장하지 않는다. 이번 적용은 건설·강화·조합과 연결되는 공통 표면이며, 새 모션 전체나 전장 아트의 전면 교체를 구현한 것은 아니다.

최종 APK의 1-3에서 창 Lv2와 봉인 Lv2를 건설하고 실제 전투의 촉매를 얻었다. 조합 메뉴의 `가능 1개`, 뇌격 레시피의 마석 40·촉매 1, 선택한 자리의 Lv1 생성·상대 재료 자리 소멸 안내를 확인했다. 봉인을 선택하자 창 자리에 뇌격 Lv1이 생성됐고 상대 자리가 비었으며 촉매가 2→1로 감소했다. 전투 중 처치 보상이 함께 발생하므로 화면의 두 재화 숫자 차이를 조합 가격의 단독 검증으로 사용하지 않는다. 생성 뒤 메뉴의 이름·단계·강화 비용 60과 촉매 반환 표시를 실제로 확인했다.

실제 Android 입력은 Computer Use로 수행했고 ADB는 QA 설치·로그·파일 대조·화면 캡처에 사용했다. 사용자5692와 보호5556/5558의 저장·입력·프로세스는 조작하지 않았다.

검증 자료는 `TestResults/city-barrier-ui-20261106/`에 있다. 이는 Unity/에뮬레이터의 구현 검증이며, 사람의 재미 평가·물리 기기·iOS·독립적인 전체 IMGUI/uGUI 화면 비교를 완료했다는 의미는 아니다.
