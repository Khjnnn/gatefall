# Gatefall 공격·피격 표현 v0.15.0

목표: 빠른 연사 → 작은 적의 명확한 명중 → 짧은 파열이 이어지며, 조합 타워의 공격 방식을 색과 형태로 구분한다. Random Dice 공식 소개는 참고했고 원본 영상/이미지의 실제 프레임 관찰에는 도구 제한이 있었다. 원본의 정확한 지속시간·입자 수·코드·에셋을 복제하지 않는다.

- 창/헌터: 수평으로 긴 탄선, 발사 방향의 짧은 섬광, 흰 명중점과 방향 선.
- 봉인: 청록색 탄선, 명중한 적 발밑의 타원 파동과 교차선. 단순 발사 시점의 가짜 명중 링은 제거한다.
- 뇌격: 실제 Hit 이벤트 사이의 금색 외곽/흰 중심 연결 번개. 날아가는 첫 탄과 연쇄 명중을 구분한다.
- 포격/파쇄: 흰 폭심 0.065초, 색이 있는 파열/지면 충격파 0.18~0.24초. 실제 범위에서 크기를 계산한다.
- 중력: 수축하는 보라 소용돌이와 범위 링. 종결: 짧은 수직 섬광과 충격파. 표식/관측창: 청색 목표 파동.
- 작은 적 처치: 몸체의 흰 실루엣이 타격 방향으로 짧게 밀리며 0.12초에 축소, 지면 링 0.15초/파편3. 큰 적은 0.18~0.25초/파편8.
- 살아남은 상세 적: 같은 0.065초 HitFlash를 전용 셰이더로 흰색에 섞고 8%의 순간 눌림. 위치/충돌/속도는 변하지 않는다.
- 화면 전체 섬광/카메라 흔들림/전투 정지는 추가하지 않는다. 몹5~8배 물량·공격수치·전멸승리·상한·저장 형식은 유지한다.

자체 V6 알파 마스크를 공유 셰이더로 중립화하여 역할별 색으로 재사용한다. 새 래스터 생성은 없으며 새 코드와 셰이더만 자체 제작한다. 일반 적은 기존 군집 메시/64x48 텍스처를 유지한다. 효과 풀220개 유지, 혼잡140개부터 작은 부수효과를 줄이며 초과 재활용도 계측한다. 효과는 실제 시간으로 사라져2배속에서2배로 길어지지 않는다.

검증: 코어6파일 해시 불변, Unity Android 컴파일/셰이더·APK 서명/16KB, 분리 Android AVD에서 창/봉인/포격/뇌격과 대량 처치·저장/상한/프레임을 확인한다. 전체 조합 전수·실기기·청감·사람의 재미 평가로 확대해 주장하지 않는다.

최종0.15.1: Android0.15.0관찰에서뇌격탄선의청록바탕색×금색색곱을발견해특수투사체에도중립알파셰이더를적용. 풀재사용시기본재질/특수재질을명시적으로재설정한다. 효과시각검증후색보정이며전투코어는같다.
