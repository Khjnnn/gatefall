# Gatefall 건설·동시 전투 확대 v0.16.0

사용자 피드백: 녹화에서 배치 공간과 실제 타워 수가 적어 보이며 여러 타워가 더 많이 싸우는 모습을 원한다.

기존 후반10지점/시작140/웨이브보급300에서0.15.1 녹화는 강화·조합을 포함한710지출로7타워였다. 기존 가격을 유지하고 공간과 전투 중 쓸 재화를 함께 확장한다. 새 종류/버튼/영구 재화는 추가하지 않는다.

| 작전 | 지점 수 | 기본 시작 마석 | 웨이브당 보급 |
|---|---:|---:|---:|
|1-1|7→14|140→240|60→80|
|1-2|10→18|140→240|60→80|
|1-3|10→14|140→240|60→80|
|1-4|12→24|200→280|60→100|
|1-5~1-9|10→24(1-8은22)|140→280|60→100|
|1-10~1-14|10→24|140→320|60→100|

총139→308지점. 좁은 합류 작전1-3은14,1-8은22로 도로/터치 이격을 우선한다. 기존139개 위치/순서를 유지하며 새 지점을 뒤에 추가한다. 추가 지점은 도로 중심에서2.15 이상 떨어지고, 후반은3.25 이내여서 사거리3.4의 방벽도 가까운 활성 도로를 덮는다. 새 지점 간격2.6 이상, 기존끼리3.45 이상. 기존 전장48×24와14개 고유 도로는 유지한다.

시작 마석은 기본140에 초반100/중반140/후반180을 더한다. 실험실과 사용자 저장 형식은 그대로다. 웨이브 지급5회 유지, 총보급은 초반400/이후500으로 늘린다. 이전300 상한은 이번 사용자 요청으로 교체한다. 카드3회/촉매2개·호출 선지급의 중복 방지·정리 시간 추가 보급 없음·영구 보상/타워 가격·적 편성/체력/속도·전멸 승리는 유지한다.

초반 준비에 기본 창6개, 후반 기본 창8개를 살 수 있다. 후반은 한 전투에12~16개 타워와 일부 강화·조합을 운용하는 것이 목표다. 실제 사격에 참여하는 지점 수와 최근3초 내 사격한 타워 수를 같은 구매 정책/3시드의 전후 모델로 비교한다. 이는 동시 렌더링이나 사람의 재미 평가가 아니다. Android 실제 터치에서 조합 후 보충·여러 전선 공격·1x/2x 영상·효과220 상한/프레임·업데이트 저장을 별도로 확인한다.

모바일 HUD에는 현재 타워 수/전체 지점 수를 마석 아래에 표시한다. 호출 보급 문구도 실제 지급액을 참조한다. 길목·기존 슬롯을 옮기거나 몬스터를 더 강하게 만들어 건설 증가를 상쇄하지 않는다. 모델이 과도한 빈 사격 지점을 보이면 배치/구매 순서를 먼저 검토한다.
