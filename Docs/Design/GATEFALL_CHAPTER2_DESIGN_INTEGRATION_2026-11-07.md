## 실제 적용 범위

- 현대 구도심 결계 장치 홈과 기본 진입 화면, 선택 작전·현재 챕터·실제 일반/위기 진행도. 홈에서 지도·편성·성장·설정·출전으로 연결한다.
- 흑연색 패널·깎인 모서리·황동 보강·민트 주요 행동을 공통화했다. 강화는 황동, 조합은 자주색, 판매는 보조 행이며 밝은 제목과 어두운 가격 칩을 사용한다.
- 건설/강화/조합·성장 카드·HUD·공통 버튼에 같은 토큰과 역할색을 적용했다. 탐색용 선형 심벌9개와 캐시된 눌림 표면4개를 포함한다.
- 기존 자체 제작 PNG6개(홈·마석·촉매·창 Lv1/Lv2·명중 알파)를 픽셀 변경 없이 옮겼다. 창의 월드 크기와 접지 pivot, 건설·강화·조합·창 명중 FX를 연결했다.
- 다솜동 지면·소품·산탄/탄막 아틀라스와 기존 다른 계열의 아트를 유지했다. 이번 통합은 제작된 디자인 전체의 적용이며 13계열 전체를 새 비트맵으로 재제작한 작업은 아니다.

## 최신 챕터2 보존

공통 Git 기준 `ab2ba77`을 이용해 표현 파일9개의24개 충돌을 검토했다. 산탄 건설명령260, 장갑 피해 안내, 탄막/종결의 실제 대상수, 세 자리 가격 폭, 챕터 전환660/661, 동적 페이지·웨이브 수, 챕터2 리소스 fallback과 생성 텍스처 정리를 유지했다. 예전14작전·6웨이브 구현으로 대체하지 않았다.

종현동14작전과 다솜동6작전, 총20작전·13타워 종류·7/8웨이브 및 v3 저장은 기존 그대로다. 전투·모바일 입력·캠페인·저장을 담당하는 Core8개는 [기준 해시](chapter2-design-20261107/core-baseline.json)와 모두 일치한다. 홈의 진행도는 `StageId`, `ChapterStart/ChapterCount`, 실제 프로필의 일반/위기 별을 사용한다. Home 열거값은 끝에 추가해 기존 화면 값도 유지했다.

기존 디자인 원본 작업 폴더의 미커밋 소스는 수정하지 않았다. 이전 기준 커밋과 APK는 보존했고, 통합 브랜치에서 검증 후 기존 `codex/chapter2-balance-20261106` 브랜치에 fast-forward로 반영했다. [원본 아트 해시](chapter2-design-20261107/original-assets.json)와 [승인 참고 이미지·제작 프롬프트](chapter2-design-20261107/reference/)도 기록했다. Git 커밋은 로컬에 보존했으며 원격 push는 하지 않았다.

새 소유 기기 `GatefallChapter2StyleV0303:5700`만 조작했다. 기존 사용자/다른 QA5556·5558·5692·5694·5696·5698은 입력·설치·종료하지 않았다. UI 입력은 Computer Use로 수행했고 ADB는 설치·파일/로그·캡처·테스트 기기 수명 관리에 사용했다.

초기 디스크 복제본은 이전 패키지/프로필을 읽지 못했다. 읽기 전용 raw 평탄화 시도도2GB 지점에서 I/O 오류로 실패해 반복하지 않았다. 최종 검증은 **이전 챕터2 QA에서 기록한 합성 v3 프로필654바이트**를 새 QA에 값 변경 없이 복사한 fixture 방식이다. 실제 사용자 프로필을 가져오거나 수정한 검증이 아니다. 이전 QA의 원본 QCOW2 SHA256은 검증 전후 `ba1eafa224bbb7edbb075fa3531ddae53ecdf5c1cff6ba4df10ca5c19a1b1a3b`로 동일하다.

1. v0.30.2를 설치해 합성 프로필의59별·506마핵·2-6 선택 상태를 실제 화면에서 확인했다.
2. v0.30.3을 `install -r`로 업데이트했다. 설치 전·기준 콜드 실행·업데이트 직후·첫 실행의654바이트 SHA256은 모두 `46c1dfb0f79bada4a977e807f398b9b42bc5bbe31aa0330f284d1714b58ef6a8`로 동일했다.
3. 홈·지도·챕터 전환·6종 편성·성장·설정·홈 복귀와 직접 출전을 확인했다. 홈의 챕터1은42/42, 챕터2는17/18로 실제 기록을 구분한다. Android2400×1080 및1280×720에서 홈을 확인했다. 일반/위기 레코드 구분의 확장 사례는 별도 Unity 합성 레이아웃 검사에서 확인했다.
