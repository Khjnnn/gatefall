# 챕터2 최신 디자인 통합

## 목표
0.30.2/142/5db6ecc7의 최신 챕터2에 승인된 모든 기존 디자인(홈·공통 버튼·카드·자원·창2단계·건설/강화/조합/명중 FX·토큰)을 통합해 현재 챕터2 작업 폴더와 새 Android APK로 전달한다.

## 단계
1. 최신 상태/근거·새 통합 브랜치·백업·코어 해시 고정 — 완료
2. 디자인3방향 통합·챕터/신규 계열/저장API에 맞춰 적응 — 완료
3. 소스/토큰/모바일/챕터2/실제 Unity·APK 검사 — 완료
4. 별도 소유 QA에서0.30.2 업데이트·v3 저장·홈/지도/챕터2/전투 메뉴·FX 검증 — 완료
5. 검토 가능한 소스/최종 APK/화면/통합 기록 전달 — 완료

## 기준
- 현재 워크트리 gatefall-chapter2, 기준HEAD5db6ecc7, 원래 clean. 새 브랜치 codex/chapter2-design-integration-20261107.
- 기존 챕터2 기준5db6ecc7와0.30.2 APK를 보존한다. 버전은0.30.3/143으로 올려 정상 업데이트한다. 검증된 통합 커밋은 기존 codex/chapter2-balance-20261106에 fast-forward로 적용한다.
- Core8개·데이터·챕터2 전장/기존 산탄/탄막 아트·7/8웨이브·v3 저장을 보존한다. 예전14작전/6웨이브 구현으로 되돌리지 않는다.
- 옮길 기준은 gatefall-unity의 실제 스타일1.3/0.28.15다. 그 작업 폴더의 미커밋 변경과 다른 문서는 건드리지 않는다.
- 기존 사용자/다른 QA(5556/5558/5692/5694/5696/5698)를 입력/설치/종료하지 않는다. 새 소유 기기를 사용한다.
- 스타일 작업에 필요한 검사는 실행하되 동일한 코어의 무관한 전투 행렬을 반복하지 않는다. 모델/에뮬레이터/실기기를 구분한다.

## 오류
- 없는 .agents/.codex 검색을 제외하고 실제 존재하는 폴더를 조회한다.
- 긴 출력이 잘려 파일 전체 대신 변경 구간과 요약을 사용한다.
- 이전 소스의 무시된 백업 파일이 현재 경로에 남아 있지 않았다. 존재하지 않는 백업을 다시 가정하지 않고 실제 공통 Git 기준ab2ba77로3방향 병합 후 충돌을 검토한다.
- QA의 첫 단순 QCOW 복제본은 부팅됐지만 이전 패키지/저장이 보이지 않아 업데이트를 진행하지 않았다. 하드웨어의 useQcow2는true이므로 단순 설정값만으로 원인을 단정하지 않는다. 소유5700만 종료하고 원본 QCOW 체인을 읽기 전용으로 raw에 평탄화한 독립 복제본을 구성한다.
- qemu-img의 raw 출력이2GB 지점에서 I/O 오류로 실패했다. 디스크 복제를 계속 반복하지 않는다. 사용자가 승인한 통합 검증의 새 합성 QA에 이전 검증에서 기록한 v3 프로필 원본(654바이트)을 그대로 복사하고,0.30.2에서 읽은 뒤0.30.3으로 정상 업데이트/첫 실행/전후 동일성을 확인하는 fixture 방식으로 전환한다. 사용자/이전 QA와 코어 값은 변경하지 않는다.
