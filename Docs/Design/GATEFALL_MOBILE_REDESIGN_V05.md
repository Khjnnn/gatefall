원본 코드, 이미지, 음원, 맵, 캐릭터는 사용하지 않는다. v0.5 아트는 모두 `Tools/art/gatefall_art.py`로 새로 생성한다.

## 3. 유지 / 통합 / 숨김

| 구분 | 내용 |
|---|---|
| 유지 | 라온시와 종현동 6작전, 각성자 이동과 자동 공격, 중앙 결계 방어, 기본 4종 건설과 Lv2 강화, 공개 조합식 6경로(재료 소비, 촉매), 인접 공명, 30/90/150초 성장 카드, 보스, 별점, 마핵, 연구, 각성자 성장, 저장 형식 |
| 통합 | 작전 지도와 브리핑을 한 화면으로 합친다(작전 노드 선택 → 오른쪽 요약 → 출전). 각성자와 결계 공방은 "성장" 화면 하나로 합친다. 기록, 소리, 실험실은 "설정"으로 옮긴다. 건설, 강화, 조합, 판매는 지점을 탭했을 때 뜨는 문맥 패널 하나에서 처리한다. |
| 제거(HUD) | 전장 지도 버튼, 사거리 버튼, 조합서 버튼, 목표 고정, 화면 밖 적 화살표 글자, 상시 설명 상자, 무음 버튼(일시정지 메뉴로 이동) |
| 규칙 단순화 | ① 캠페인과 실험실에서는 지점이 멀어도 탭해서 건설, 강화, 조합, 판매할 수 있다. 접근 조건은 Rules가 없는 구형 시뮬레이션에만 남긴다. ② 응급 방호는 버튼 대신 결계 HP가 50% 미만이면 자동으로 발동한다(35초 재사용, 5초 피해 60% 감소). 상시 스킬 버튼은 각성자 고유 스킬 1개만 둔다. |
| 개발자 전용 | 전투 실험실은 설정 화면 맨 아래에 "개발용"으로 분리한다. |

새 모드, 재화, 성장 트리, 타워 종류는 추가하지 않는다. 해금 순서는 기존 그대로다: 1-1 창 → 1-2 봉인과 공명 → 1-3 촉매와 뇌격 → 1-4 붕괴, 파쇄, 중력 → 1-5 방벽과 종결 → 1-6 보스.

## 4. 아트 방향 — 하나로 고정

- **장르 표현**: 휴대폰에서 선명하게 읽히는 스타일라이즈드 2D 현대 도시 판타지. 라온시 구도심의 낡은 아스팔트, 보도블록, 상가 옥상, 방위대 바리케이드 위로 검은 탑이 솟아 있다.
- **시점**: 탑다운 3/4. 물체는 윗면과 남쪽 옆면을 보여 준다.
- **광원**: 왼쪽 위(북서). 그림자는 오른쪽 아래로 부드럽게 떨어진다.
- **외곽선**: 유닛, 타워, 결계에만 일정한 두께의 잉크선(#1B2230)을 넣는다. 배경에는 외곽선을 넣지 않아서 전경과 배경의 계층을 분리한다.
- **명도와 채도**: 배경은 중간 명도에 낮은 채도(회청색 아스팔트, 따뜻한 회색 보도). 강조색은 아래처럼 의미별로 제한한다.
  - 아군 결계: 청록 #3FD6C6
  - 적과 위협: 자홍과 진홍 #E0406A, 검은 수정
  - 창: 호박색 #F0B340
  - 봉인: 청록 계열 #39C2B4
  - 붕괴: 주황 #F07438
  - 방벽: 강철 청색 #6E9CE0
  - 뇌격: 금색과 전광 / 파쇄: 호박과 주황 / 중력: 남보라 #6B5BD6 / 종결: 백금
- **타워 실루엣**: 창은 높고 가는 첨탑, 봉인은 낮고 넓은 고리, 붕괴는 낮고 무거운 육각 박격포, 방벽은 가로 벽 모양 아치. 조합 결과는 재료의 형태를 결합한다. 뇌격은 첨탑에 코일, 파쇄는 육각에 첨탑, 중력은 고리에 떠 있는 구체, 종결은 세 기둥 왕관. Lv2는 높이, 부품, 금속 띠가 추가된다.
- **공격 표현**: 창은 빠른 빛창, 봉인은 대상에 고리 펄스, 붕괴는 포물선 포탄과 폭발 원, 뇌격은 꺾인 연쇄 번개, 파쇄는 굵은 탄과 파편, 중력은 소용돌이, 종결은 빛기둥, 방벽은 붙잡을 때 방패 호.
- **UI**: 진한 슬레이트 반투명 패널(모서리 12, 경계선 1px), 1순위 행동은 호박색 버튼 하나, 나머지는 슬레이트. 네온, 블룸, 유리 효과는 쓰지 않는다. 서체는 나눔고딕 Regular/Bold/ExtraBold(OFL)로 통일한다. 아이콘은 2톤 단순형. 중요 버튼은 높이 54 기준 단위 이상(약 48dp 이상)으로 만든다.
- **이미지에 글자를 넣지 않는다.** 모든 글자는 Unity에서 그린다.

## 5. 화면 흐름

`작전 지도(노드 선택 → 요약 → 출전)` → `배치 준비(시간 정지, 지점 탭 건설, 범람 시작)` → `약 3분 방어` → `결과(별점, 마핵, 다음 작전)` → 작전 지도에서 다음 작전이 선택된 상태로 돌아온다.

- 전투 HUD: 왼쪽 위 결계 HP 바, 가운데 위 남은 시간과 6구간 진행 막대, 오른쪽 위 마석, 촉매, 일시정지. 왼쪽 아래 조이스틱, 오른쪽 아래 스킬 1개. 각성자 HP는 머리 위 바로 표시한다.
- 문맥 패널: 빈 지점이면 해금된 기본 결계주 타일을 한 번 탭해 건설. 타워가 있으면 강화(변화 수치), 조합(결과 아이콘, 비용, 짝 위치 표시), 판매. 바깥을 탭하면 닫힌다. 패널이 열려 있는 동안 전투는 멈춘다(기존 규칙).
- 튜토리얼: 1-1에서 손가락 표시로 "탭해서 건설", "탭해서 강화", "범람 시작"을 안내한다. 1-2에서 공명, 1-3에서 첫 조합을 한 줄 안내로 순서대로 가르친다.

## 6. 후속 구현·검증에서 반영한 결정

- 조합 패널은 해금된 관련 조합을 모두 표시한다. 앞의 두 경로로 잘라 세 번째 종결 경로를 숨기지 않는다. 가능한 짝이 하나면 결과 버튼 탭으로 바로 조합하고, 여러 짝이면 전장의 강조된 지점을 선택한다. 조합물의 결과 지점은 처음 선택한 타워 자리다.
- 강화 전후 정보는 `피해 14→22`, `연쇄 24→30 · 감속 25→30%`처럼 짧게 표시한다. 역할 설명과 효과가 겹쳐 긴 문장으로 흐르지 않게 한다.
- 강화 미리보기는 선택한 자리의 인접 공명과 현재 연구·성장 카드를 함께 반영한다. 실제 Android에서 공명 중인 창의 `15→23` 표시와 강화 후 `23`이 일치하는 것을 확인했다. 미리보기가 타워 단계나 재화를 변경하지 않는 회귀 검사도 포함한다.
- 상시 버튼은 일시정지와 고유 스킬 **총2개**다. 스킬2개라는 초기 인계 표현은 잘못됐다. 자동 응급 방호에는 버튼이 없다.
- 실제4:3 실행에서 지도 후반 노드가 브리핑 뒤로 가려졌다. 지도 전체를 왼쪽 영역 안에 맞춰 모든 노드가 보이게 변경했다. 성장 화면은 초상화 크기를 제한하고 설명·연구 단계·구매 버튼의 영역을 분리했다. 16:9와 긴 휴대폰 화면도 따로 검사한다.
- API35 ARM 번역 환경에서 Vulkan debug object label 네이티브 충돌이 재현돼 Android 그래픽 API를 OpenGLES3로 고정했다. 이 게임의2D 표현을 유지하는 호환성 조치다. 실제 휴대폰 성능과iOS는 별도 검증 대상이다.
- 타워·레시피·성장 트리·재화 수는 늘리지 않았다. 기존 저장 형식과 해금 순서를 유지했다.
