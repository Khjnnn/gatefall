# v0.13.0 전투 물량·속도·처치감

사용자 요청: Random Dice를 참고해 더 많은 적을 빠르고 부드럽게 처치하는 모바일 전투. 기존 14개 길목과 배치·강화·조합, 캠페인 전멸 승리를 유지한다.

## 참고 범위

[Random Dice 공식 Google Play 소개](https://play.google.com/store/apps/details?id=com.percent.royaldice)의 빠른 타워 디펜스·소환/강화/합성 흐름을 방향으로 참고했다. 보관된 정적 분석 보고서는 원본 적 수치/연사/효과 타이밍을 확인하지 못했다. 아래 수치는 Gatefall 자체 설계이며 타 게임 코드·에셋·정확한 수치의 이식이 아니다. 소개 영상은 도구로 열리지 않아 영상 관찰을 근거로 삼지 않았다.

## 제품 변경

- 각 기존 적 편성에 약한 일반 적 1개를 같은 입구에 0.12초 차이로 추가한다. 기존 빠른 적·정예·공성·보스의 개수와 방향은 보존한다. 보스는 복제하지 않는다. 총 1-1 66→132, 1-4 128→256, 1-6 148→295. 6웨이브/30초 배치와 기존 예고·선택 호출을 유지한다.
- 일반 적 체력은 이전의 36%, 이동은 1.35배. 빠른 적 체력은 75%, 이동 1.2배. 정예/공성 체력은 그대로, 이동만 각각 1.15/1.1배. 보스 체력·속도는 그대로다. 캠페인에만 적용한다.
- 창 공격 간격 .70→.46초. 다른 공격 타워와 헌터는 기존 간격의 .85배, 결계 재충전은 그대로. 타워/헌터 탄속 18/21→28/30. 가격·사거리·조합 재료는 유지한다.
- 처치 재화는 적 종류별 기존 금액을 유지한다. 추가 일반 적만큼 전투 재화가 늘어 후반 보충·강화 기회를 늘린다. 영구 보상/저장 형식, 보급 5회·300/카드 3회/촉매 2개는 그대로다.
- 피격은 짧은 밝기 변화, 처치는 0.16초 수축 잔상·짧은 금빛 파열/파편·옅은 연무. 정예와 보스의 파열은 더 크다. 타워에는 짧은 반동, 적 이동에는 지수 보간을 적용한다. 도로·판정·터치 영역은 이동시키지 않는다.
- 짧은 자체 생성 타격음과 빠른 연속 처치 시 최대 1.175 피치 변화를 적용한다. 소리 중첩은 최소 .045초 간격으로 제한한다. 전체 화면 섬광/화면 흔들림/전투 정지는 추가하지 않는다.
- 일반 효과는 최대 220개, 레코드·렌더러를 재사용하며 초과 시 가장 오래된 효과를 회수한다. 보스 위험 원·타워 사거리 표시는 별도라 이 상한으로 지워지지 않는다. 개발 로그에 현재/최대 효과 수를 남긴다.

## 검증 방법과 판정

`TestResults/pace-v0130-baseline`의 변경 전 코어와 현재 코어를 별도 프로세스에서 동일한 검증기로 비교한다. 각 14작전×4정책×3시드=168조건, 기본 헌터/영구 성장 없음/첫 카드/호출 없음/자동 스킬과 보스 회피. 고정 초기 배치는 시작 재화만 지출한다. 나머지는 3초 간격으로 구매한다. 자동 구매 정책이며 사람의 조작이나 재미 평가가 아니다.

이동을 고정한 2거리 단일 타워 대결 24조건은 첫 발사부터 처치까지의 시간/발사 수를 기록한다. 실제 움직이는 적의 평균 수명이나 전체 전투 난이도로 확대 해석하지 않는다. 일반 적은 카드/영구 성장 없이 1~3발, .06~1.00초. 초반 강화 창은 1발, 1-4 강화 창은 기본 2발이다. 더 높은 체력의 정예·공성은 유지한다.

동일 정책 비교에서 분산/강화는 이전과 현재 각각 42/42승, 조합 후 보충은 27→36승, 고정 초기 배치는 3→9승. 초기 세 작전의 능동 보강 정책 27조건은 결계 300을 유지한다. 조합 정책의 1-8/1-12 실패는 남아 있으며 모든 배치를 보장하지 않는다. 시드별 편성이 같아 같은 결과가 나온 조건은 무작위 강건성 증거로 간주하지 않는다.

최종 Android 설치·실제 입력·조합·전멸·저장·프레임 결과는 별도 `TestResults/runtime-v0130.md`에 기록한다. 모델 시간은 기기 프레임 성능이 아니다. 사람의 재미 평가·실기기 발열/배터리·iOS는 보류다.

동일 모델 행렬의 관측 최대 잔여 적은35→60,1전투초 안의 최대 처치는4→7,승리 조건들의 평균 처치/초는.55→1.15다. 고정 배치/실패 조건도 포함한 전체 행렬의 최대값이므로 특정 실기기의 평균 화면 밀도/프레임이나 사람의 쾌감 수치가 아니다. 최종 Android1-1은 창3개 Lv1/120지출만으로182.12초132전멸·결계300·3별/보상10·저장 확인. 카드 선택은 빛창→사거리→빛창이며 이전 버전과 완전히 같은 카드 순서인 비교로 주장하지 않는다.
