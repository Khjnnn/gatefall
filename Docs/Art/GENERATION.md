# Gatefall original art — provenance history

## Current asset provenance — 2026-11-01

The historical v0.5 generator inventory below is not the current asset count. The current v0.24.3 delivery adds one original built-in imagegen texture at `Assets/Resources/Art/V12/district-training-ground.png`, limited to stage1-11. The1774x887 RGB24 generated bytes are preserved unedited; actual Unity import is512x256/max512. Prompt, tool mode and source are recorded in [the training-ground asset record](../Design/GATEFALL_TRAINING_GROUND_ASSET_2026-11-01.md). Existing own stone floor and historical source records are preserved. No other-game code/art input was used. Refer to `runtime-v0243.md` and `runtime-v0243-double.md` for UI versus completed replay scopes.

## Historical v0.5 assets

The current game loads78 original PNGs from `Assets/Resources/Art/V5`. Claude implemented the deterministic generators in `Tools/art/`; entry point `python Tools/art/generate_all.py`. This set was generated by drawing code, **not the image_gen service**. It includes6stage backgrounds,15tower variants,5enemies,3hunters,8UI skins,22icons,16effects,core,pad,and district map. Previews: `Docs/Art/v05-previews/`.

The style uses consistent upper-left light, ink outlines on actors, low-saturation city backgrounds and role-specific silhouettes. PNG alpha, original non-power-of-two dimensions and texture imports are checked in `PrototypeTools.ImportArtwork`. Font weights use NanumGothic under the bundled OFL. No extracted Realm/Random Dice art is included.

The earlier image_gen assets described below are preserved at `Docs/Art/legacy-v04/`; their former `Assets/Resources/Art/*.png` locations are historical. These prompts are provenance for v0.3/v0.4, not a claim that v0.5 art was generated by an image model.

## Archived v0.3/v0.4 image generation

Generated with the built-in image_gen tool. User requested new assets matching the modern-fantasy concept. No Realm Defense extracted graphics were provided to the generator or imported. These are prototype raster assets, combined with Gatefall's original procedural effects and silhouettes. Alpha is preserved; Unity import downsizes props to512 and the background to2048. Source PNG files remain unmodified.

Use case: stylized-concept. Asset type: original production background texture for a Unity top-down 2D mobile tower defense game named Gatefall. Create a polished hand-painted orthographic overhead urban district at night, in a modern Korean-inspired city invaded by magical gates. Landscape composition around 1.8:1. Strictly overhead, no horizon, no perspective tilt. The central 80 percent should be a continuous low-contrast dark blue-gray asphalt and concrete plaza, subtly weathered paving slabs, drainage channels, tiny scattered rubble, faded urban ground markings. Keep the central gameplay floor open and broadly uniform: absolutely no buildings or objects in the central playable area and no painted major roads, no towers, no people, no vehicles, no portals. Only along the far outside edge and corners place modest rooftop silhouettes, utility housings, broken curb edges, low barriers and sparse dim teal city lights. Fine painterly material detail but restrained contrast so bright gameplay units remain readable. Night navy, desaturated slate concrete, subtle cyan reflected light, tiny warm amber edge details. Fill the image edge to edge with the environment. No labels, text, logos, watermark, UI, border or vignette. Entirely new art; do not reproduce any existing game's assets.
