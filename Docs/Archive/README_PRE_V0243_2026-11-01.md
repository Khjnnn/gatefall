# Gatefall — 라온시 · v0.18.4

귀환자 강윤과 제7방위대가 검은 탑의 범람을 막는 모바일 디펜스입니다. 종현동14개 작전에서 각성자를 움직이고, 자동 공격과 결계주 강화·조합으로6개 웨이브의 모든 마수를 처치하며 도시 결계를 지킵니다.

**Android 우선 개발 중입니다.** iOS는 후속 대상이며 이번 전달에 IPA는 없습니다. PC는 Unity Editor·검사·에뮬레이터 개발 도구로 사용합니다. 과거 Windows 배포물은 보존하지만 새 PC 제품 빌드는 만들지 않습니다.

## 설치와 실행

- Android APK: [Gatefall-v0.18.4.apk](Builds/Android/Gatefall-v0.18.4.apk), 동일 내용의 [Gatefall.apk](Builds/Android/Gatefall.apk).

## 플레이

작전 지도에서 구역을 탭하고 **출전** → 시간을 멈춘 상태에서 배치 → **범람 시작** → 6웨이브 및 잔여 적 처치 → 별점·마핵 → 다음 작전으로 진행합니다. 메뉴는 작전 지도, 성장, 설정과 해금 후 결계주 편성 화면입니다. 세계관은 짧은 작전 대사와 전장으로 전달합니다.

출전 전 헌터 칩에서 교체하면 해당 헌터의 전투 역할을 확인할 수 있습니다. 등급과 성장은 성장 화면에서 확인합니다.

| 행동 | 모바일 조작 |
|---|---|
| 각성자 이동 | 왼쪽 조이스틱. 공격은 자동 |
| 건설 | 빈 건설 지점 탭 → 해금된 결계주 선택 |
| 강화·조합 | 세운 결계주 탭 → 같은 패널에서 선택 |
| 조합 재료 | 후보가 하나면 바로 조합, 여러 개면 강조된 짝을 선택 |
| 판매 | 판매를 두 번 눌러 확정 |
| 고유 스킬 | 오른쪽 아래 버튼 1개 |
| 일시정지 | 오른쪽 위 정지 버튼. 앱 이탈도 자동 정지 |
| 전투 배속 | 전투 중 남은 시간 오른쪽의 `1×` / `2×` 버튼으로 전환. 새 전투는 1×로 시작 |
| 1-4 전장 보기 | 오른쪽 위 전체 보기 / 추적 보기 전환. 화면 밖 적은 방향과 수로 표시 |
| 패널 닫기 | 패널 바깥 탭 |

건설·강화·조합·판매는 해당 지점으로 걸어갈 필요 없이 처리합니다. 전투 중 타워 메뉴와 조합 짝 선택을 열어도 전투는 계속됩니다. 메뉴를 조작하는 동안 각성자 이동 입력은 잠기며, 성장 카드 선택과 일시정지 중에는 전투가 멈춥니다. 응급 방호는 결계 HP가 50% 미만일 때 자동 발동합니다(5초 피해 60% 감소, 재사용 35초).

캠페인은 모든 예약 적이 출현하고 남은 적을 모두 처치했을 때 결계가 남아 있으면 승리합니다. 180초에 적이 남아 있으면 전투를 계속하고, 마지막 적을 일찍 처치하면 그때 승리합니다. 1-6은 문지기까지 처치해야 합니다. 상단에서 웨이브·경과 시간과 최종 출현 후 잔여 적 수를 확인합니다.

헌터가 쓰러져도 결계가 남아 있으면 전투는 계속됩니다. 헌터는 전투 시간 10초 후 결계 근처에서 체력을 회복해 부활하고 2초간 무적입니다. 대기 중에는 이동·공격·스킬을 사용할 수 없지만 타워는 계속 싸우며 건설·강화·조합도 가능합니다. 일시정지와 성장 카드 선택 중에는 부활 시간도 멈추고, 2배속에서는 전투 시간과 함께 빠르게 진행됩니다.

### 첫 조합

1-3에서 창Lv2(40+30)와 봉인Lv2(45+40)를 준비합니다. 60초에 받은 촉매1개와 추가40마석으로 뇌격을 만듭니다. 선택한 결과 지점에 조합물이 남고 두 재료는 소비됩니다.

| 재료 (모두 Lv2) | 결과 | 추가 마석 / 촉매 |
|---|---|---|
| 창 + 봉인 | 뇌격 | 40 / 1 |
| 창 + 붕괴 | 파쇄 | 45 / 1 |
| 봉인 + 붕괴 | 중력 | 45 / 1 |
| 뇌격 + 붕괴 | 종결 | 80 / 1 |
| 파쇄 + 봉인 | 종결 | 75 / 1 |
| 중력 + 창 | 종결 | 75 / 1 |
| 표식 + 창 | 관측창 (1-14 클리어 후) | 40 / 1 |

조합물 Lv2 비용은60마석입니다. 종결까지 각 경로의 누적 비용은455마석·촉매2개입니다. 준비 중 판매는 투자 마석100%, 전투 중75%와 투자 촉매 전량을 반환합니다. 캠페인은 시작140마석(1-4는200),30초마다60마석씩5회,처치 보상 별도입니다. 촉매는 해금 후60/120초 지급합니다.

성장 화면에 각성자 선택·승급과 연구를 통합했습니다. 마핵은 영구 재화로 1-1~1-6 첫 보상 합계90, 재클리어2, 패배0입니다. 연구 초기화는 실제 연구 지출만 전액 돌려줍니다. 별점은 최대 결계 침식 기준10% 이하3개/30% 이하2개/그 밖의 승리1개입니다.

세희·백도하는 해금 직후 첫 성장1회를 각각12·18마핵으로 구매할 수 있습니다. 강윤은 기존 첫2회와1-6 첫 봉인 후3회차 범위를 유지하며 추가 성장은 후속 구역에서 열 예정입니다. v0.11.1은 표식의 효과 없는 공명 표시도 수정했습니다. 실제 검증 범위는 [v0.11.1 기록](TestResults/runtime-v0111.md)을 참고하세요.
